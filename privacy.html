개인정보처리방침

Compass Studio · 시행일 2026-10-14

1. 누가 쓰는가

Compass Studio는 YouTube 채널 "콤파스 딥리서치"의 운영자 한 사람이 자기 채널에만 쓰는 개인용 도구입니다. 다른 사용자를 받지 않습니다.

2. 접근하는 Google 사용자 데이터

운영자가 Google 동의 화면에서 허용한 범위 안에서만 운영자 자신의 데이터에 접근합니다.

  • YouTube 업로드: 운영자의 영상을 운영자 채널에 비공개로 올립니다.
  • YouTube 계정 관리(force-ssl): 올린 영상의 공개 상태를 읽고, 운영자 이름으로 댓글을 답니다.
  • YouTube 읽기 전용: 운영자 채널의 이름과 영상 목록을 읽습니다.
  • YouTube Analytics 읽기 전용: 운영자 채널의 조회수·시청 지속률·구독자 증감 같은 성과 지표를 읽습니다.

3. 쓰는 목적

영상 업로드, 댓글 게시, 운영자 채널의 성과 분석에만 씁니다. 광고, 프로필 작성, 판매에 쓰지 않습니다.

4. 저장

인증 토큰과 성과 기록은 운영자 개인 컴퓨터에만 저장합니다. 토큰 파일은 운영자 계정만 읽을 수 있게 권한을 제한합니다. 별도 서버나 클라우드 데이터베이스에 보내지 않습니다.

5. 제3자 제공

Google 사용자 데이터를 누구에게도 팔거나, 넘기거나, 공유하지 않습니다.

6. Google API 정책 준수

Compass Studio가 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API Services User Data Policy를 따르며, 제한적 사용(Limited Use) 요구사항을 포함합니다. YouTube 데이터는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.

7. 권한 철회와 삭제

운영자는 Google 계정의 서드파티 액세스 페이지에서 언제든 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없고, 운영자 컴퓨터의 토큰 파일과 성과 기록은 운영자가 직접 지웁니다.

8. 문의

이 도구는 운영자 본인만 쓰므로 외부 문의 창구를 따로 두지 않습니다. 채널 관련 문의는 YouTube 채널을 통해 할 수 있습니다.

English summary. Compass Studio is a personal tool used only by the owner of the YouTube channel "Compass Deep Research". With the owner's consent it uses the YouTube Data API (upload, force-ssl, readonly) and the YouTube Analytics API (readonly) solely to upload the owner's videos as private, post the owner's comments, and read the owner's channel analytics. Tokens and statistics are stored only on the owner's personal computer and are never sold, transferred or shared. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
